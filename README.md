# Mimi | Portfolio

Interactive portfolio website with a notebook interface, Three.js 3D elements, and a custom sticker system.

## 🚀 Quick Start

1. Clone: `git clone https://github.com/yourusername/portfolio.git`
2. Open `index.html` in a browser (or use a local server for full functionality)

## 📦 GitHub Pages

1. Push to GitHub
2. Go to **Settings** → **Pages** → Select `main` branch
3. Your site will be live at `https://yourusername.github.io/portfolio`

## 📁 Structure

```
portfolio/
├── index.html    # Main site (all-in-one)
├── *.png/jpg     # Project images
└── README.md
```

## ⚠️ Note

Place all your image files in the same directory as `index.html`, or update the image paths accordingly.
